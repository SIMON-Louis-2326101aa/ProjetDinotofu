# Dinotofu   

Dinotofu is a C++17 RPG / arena game. The terminal version remains the stable base, and the experimental HTML/JS graphical interface is now complete enough to move the project into the V2 milestone.   

## Current version   

- Current version: **V2.04.08**   
- Last character version still acceptable before a strong recreation recommendation: **V2.01.03**   
- Characters older than **V2.01.03**: recreation recommended, because the GUI/save/bestiary/legend baseline changed too much since the older milestones.   
- V1 to V2 transition or too-old V2 save: strong recreation recommendation, because old characters are now too far from the V2.01.03 baseline.   
- Important save baseline: **V2.01.03**, because the legend register and part of the lore bestiary were restructured.   

## What is already in the game   

The game already lets you:   

- create, load and save accounts/characters;   
- choose race, class, difficulty and some protected special identities;   
- fight in AI PvP, two-player PvP, monster PvE, solo boss and coop boss modes;   
- manage inventory, weapons, armor, consumables, materials, durability, repair and qualities;   
- buy, sell, barter, visit places, consult the guild and library;   
- explore biomes with resources, chests, traps, mimics, tracks, events, dangerous locations and encounters;   
- follow guild, client, exploration, combat, delivery and bestiary quests;   
- consult an evolving bestiary with knowledge levels, dangers, habitats, known weaknesses/resistances, loot and a separate **Legend Register**;   
- use hidden systems such as codes, altered data, special characters and some lore events;   
- prepare future durable skills linked to classes, races, weapons and gameplay habits.   

Story mode is visible but intentionally waiting. It will become a real major phase later.   

## Experimental graphical interface   

The current GUI is designed to make the game playable from a local page while keeping the terminal as fallback. It reads JSON snapshots generated by the game, displays menus/combat/cards, then sends choices back to the terminal through a command queue.

## Useful commands   

Build:   

```bash   
make   
```   

Run:   

```bash   
make run   
# or   
make launch   
```   

Print the version only without starting the interactive game:   

```bash   
./output/Dinotofu --version   
# or   
./output/Dinotofu -v   
```   

Quickly check terminal accents/UTF-8:   

```bash   
./output/Dinotofu --encoding-check   
```   

Clean:   

```bash   
make clean   
```   

Rebuild:   

```bash   
make rebuild   
```   

Launch the local GUI preview:   

```bash   
make gui-preview   
```   

## Install from a GitHub release   

To install Dinotofu without manually building the project:   

1. go to the GitHub repository page;   
2. open the latest **Release** shown on the right side of the repository;   
3. download the launcher matching your operating system: Windows or Linux;   
4. run that launcher so it can open the right version of the game.   

On desktop Windows/Linux builds, the installer or launcher must create two clear entries:   

- **ProjetDinotofu Launcher**: normal / Auto launch through the OS-specific launcher;   
- **ProjetDinotofu Launcher Terminal version**: forced terminal launch through the matching Windows/Linux launcher.   

## Quick structure   

- `src/`: C++ game code;   
- `include/`: C++ headers;   
- `assets/config/`: reference JSON data;   
- `tools/gui/`: experimental graphical interface and local server;   
- `tools/windows/` and `tools/linux/`: launchers/installers;   
- `scripts/`: packaging, version, release and checks;   
- `release/`: manifest and publication data;   
- `assets/saves/`: local save folders, without private data in ZIP packages.

## Special developer note   



Hello, future adventurer, future hero, future statistically probable corpse.   

Welcome to Dinotofu. Here, you can win with real strategy, die because you tried to be clever, or discover that a fiscally motivated goblin can sometimes be more dangerous than a mythical boss. The game is still under construction, but it already exists to be played, broken, criticized, trolled, improved and retested.   

I want Dinotofu to stay free: you can optimize, try stupid things, die like a legend or survive when you clearly did not deserve it. If a mechanic frustrates you, if a boss feels unfair, if a strategy destroys balance, or if an idea makes you want to keep playing, say it. The game must grow with player feedback, not only with my ideas in my corner.   

Challenge number one: survive long enough to understand what is happening.   

Challenge number two: beat a boss without saying the game cheats. Spoiler: maybe it cheats sometimes, but at least it does it with style.   

Challenge number three: find a strategy that breaks the game, show it to me, and let me pretend it was planned from the start.   

Play seriously, but not too seriously. Complain if needed, suggest ideas, politely insult bosses, and most importantly tell me what makes you want to start another run. If you find a combo that is too strong, I will probably deny panicking after seeing the numbers, then I will say it was an advanced balancing test and everything was planned from the start. That is false, but it sounds more professional.   

If you manage to become a legend in Dinotofu, congratulations. If you die against the first enemies, congratulations too, but differently. If you lose against a chest, a trap or your own confidence, know that the game does not judge you. I do a little, but affectionately.
