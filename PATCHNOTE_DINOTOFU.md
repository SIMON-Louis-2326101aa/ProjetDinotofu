# V3.43.00 — Image settings policy, terminal lock and backup point

- Added a saved graphical image preference on the player profile.
- Terminal mode now forcibly keeps images disabled and cannot enable them.
- Settings menu explains that images are supplementary only.
- GUI JSON exports now expose the visual asset policy: `supplementary_only_no_hidden_information`.
- City/map visual planning reminds that every cost, condition, danger, distance and reward must remain available in text.
- This version is a safe bridge toward pixel-art usage without reducing accessibility or terminal reliability.
