# V3.43.00 — Paramètres d’images, verrou terminal et point de sauvegarde

- Ajout d’un réglage sauvegardé pour les images IG sur le profil joueur.
- Le terminal force maintenant les images sur désactivées et ne peut pas les activer.
- Le menu Paramètres rappelle que les images sont uniquement supplémentaires.
- Les exports JSON IG exposent maintenant la politique visuelle : `supplementary_only_no_hidden_information`.
- Les écrans ville/carte rappellent que coûts, conditions, dangers, distances et récompenses doivent toujours rester écrits.
- Cette version prépare l’usage des pixel-arts sans réduire l’accessibilité ni la fiabilité du terminal.
