DINOTOFU - OUTILS WINDOWS

FICHIERS JOUEUR / CLIQUABLES
- Installer-Dinotofu.cmd : petit lanceur local historique de l installer PowerShell.
- Lancer-Dinotofu.cmd : lance le jeu. Le mode Terminal est force par defaut.
- Lancer-Dinotofu-Terminal.cmd : ancien alias explicite Terminal conserve pour compatibilite.

MOTEURS INTERNES
- DinotofuInstaller.ps1 : vrai moteur d installation/mise a jour Windows.
- DinotofuLauncher.ps1 : vrai moteur de lancement et de mise a jour Windows.
- Publier-DinotofuPatch.ps1 : outil developpeur de publication, pas un lanceur joueur.
- dinotofu-installer.config.example.json : exemple de configuration.

IMPORTANT
Il n existe pas encore de "Dinotofu application" graphique native. Le jeu jouable est actuellement Dinotofu.exe en mode Terminal. La GUI actuelle est experimentale et sera refaite plus tard comme application desktop.
