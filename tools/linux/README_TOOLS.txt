DINOTOFU - OUTILS LINUX / DEBIAN

FICHIERS JOUEUR / CLIQUABLES
- Installer-Dinotofu.sh : petit alias historique vers le moteur d installation.
- Lancer-Dinotofu.sh : lance le jeu; le mode Terminal est le mode par defaut.
- Lancer-Dinotofu-Terminal.sh : ancien alias explicite Terminal conserve pour compatibilite.

MOTEURS INTERNES
- DinotofuInstaller.sh : vrai moteur d installation/mise a jour Linux.
- DinotofuLauncher.sh : vrai moteur de lancement et de mise a jour Linux.
- dinotofu-installer.config.example.json : exemple de configuration.

IMPORTANT
Il n existe pas encore de paquet "application" graphique natif. Le binaire jouable est Dinotofu en mode Terminal. La GUI actuelle est experimentale et sera refaite plus tard comme application desktop.
