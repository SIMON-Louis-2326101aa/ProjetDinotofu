# Branding Dinotofu   

Assets officiels confirmés en V3.49.00.   

## Rôle des fichiers   

- `dinotofu_logo.png` : logo principal du jeu et référence de marque.   
- `dinotofu_site_logo.png` : logo prévu pour site/web/présentation.   
- `dinotofu_banner.png` : bannière officielle avec personnages du monde.   
- `dinotofu_intro_cover.png` : couverture/menu d’introduction graphique.   
- `dinotofu_launcher_graphical.png` / `.ico` : icône launcher/raccourci normal.   
- `dinotofu_launcher_terminal.png` / `.ico` : icône launcher/raccourci terminal.   
- `dinotofu.ico` : favicon/icône générique.   
- Les variantes `_512.png` servent aux raccourcis Linux, au site et aux petits affichages.   

## Règle importante   

Ces images sont actives pour l’identité visuelle, les launchers et l’IG. Elles restent décoratives : aucune information de gameplay ne doit disparaître parce qu’une image est affichée. Le terminal ne doit pas afficher d’images de gameplay.
