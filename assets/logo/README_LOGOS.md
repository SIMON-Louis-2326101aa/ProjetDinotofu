# Logos Dinotofu   

Images fournies et renommées proprement pour éviter les noms ambigus.   

- `banniere_app.png` : bannière/fond principal de l’application.   
- `logo_app.png` : logo général Dinotofu.   
- `logo_ig_version.png` : icône/illustration de la version interface graphique.   
- `logo_terminal_version.png` : icône/illustration de la version terminal.   

Les copies normalisées utilisées par les launchers et l’IG restent dans `assets/branding/`.
